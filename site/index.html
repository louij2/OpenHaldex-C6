OpenHaldex-C6 louij2 fork · install from your iPhone

A community fork of the Forbes Automotive OpenHaldex-C6 firmware, with extra fixes. Not affiliated with Forbes Automotive. You only need your iPhone. Your settings normally carry over, and you can switch back to the official firmware at any time.

Before you start

  • Car parked, engine off, ignition on. The controller refuses updates unless the car is stationary.
  • If your controller has Settings → Backup & Restore, tap Export Config first. It's your safety net.

1 Download the two files

Do this while you still have internet, before going to the car.

Download firmware.bin Download littlefs.bin

Safari asks “Download?” → tap Download. Both files go to Files → Downloads.

2 Connect to the controller

  1. Settings → Wi‑Fi → join OpenHaldex-C6 (or the name you gave it). If the iPhone says “No Internet Connection”, that's normal, so stay connected.
  2. In Safari open 192.168.1.1, then the OTA tab.

3 Firmware first

  1. Find the card Update from Files (called OTA Update on some older versions).
  2. Update Type: Firmware (application)
  3. Binary: choose firmware.bin from Downloads → Upload.
  4. Wait about a minute while it restarts. If the iPhone drops the controller's Wi‑Fi, join it again and reopen 192.168.1.1.
  5. In the OTA tab, Firmware must now show the new version. If it still says 9.00.0, stop and see “If it doesn't work” below.
Why firmware first?

Some early 9.0.0 builds have a faulty uploader. If a firmware upload fails, nothing changes: the controller simply keeps its old firmware. Doing the firmware first means the next step runs on the fixed uploader.

4 Then the web interface

  1. Same card. Update Type: Filesystem (web UI)
  2. Binary: choose littlefs.bin → Upload.
  3. When it says complete, reload the page. Done!

Back to the official Forbes firmware

Easiest: on the controller, OTA → Release source → Forbes Automotive (official) → Check for updates → Switch to official. The phone needs internet for this, so set up Home WiFi (Bridge Mode) on the same OTA tab.

No home Wi‑Fi? Download the official files and repeat steps 2–4 with them:

Official firmware.bin Official littlefs.bin

Official version: 9.00.0. If you download the same file name twice, iPhone saves the second one as firmware-1.bin, so pick the newest.

If it doesn't work

  • Still 9.00.0 after step 3: your controller has one of the early 9.0.0 builds whose uploader can't finish. Nothing was changed. It needs a one-time USB update from a computer (a garage can use the official web installer). After that, this page works from your phone. A USB update can reset settings, so export them first.
  • Can't see the controller's Wi‑Fi: it turns Wi‑Fi off after 5 minutes without CAN traffic. Switch the ignition on.
  • “OTA BLOCKED”: the car must be stationary with the ignition on.

Prima di iniziare

  • Auto ferma, motore spento, quadro acceso. Il controller blocca gli aggiornamenti se l'auto non è ferma.
  • Se nel controller c'è Settings → Backup & Restore, tocca prima Export Config. È la tua copia di sicurezza.

1 Scarica i due file

Fallo quando hai ancora internet, prima di andare in auto.

Scarica firmware.bin Scarica littlefs.bin

Safari chiede «Scaricare?» → tocca Scarica. I file finiscono in File → Download.

2 Collegati al controller

  1. Impostazioni → Wi‑Fi → scegli OpenHaldex-C6 (o il nome che gli hai dato). Se l'iPhone dice «Nessuna connessione a Internet» è normale: resta collegato.
  2. In Safari apri 192.168.1.1, poi la scheda OTA.

3 Prima il firmware

  1. Trova il riquadro Update from Files (su alcune versioni vecchie si chiama OTA Update).
  2. Update Type: Firmware (application)
  3. Binary: scegli firmware.bin da Download → Upload.
  4. Aspetta circa un minuto mentre si riavvia. Se l'iPhone perde il Wi‑Fi del controller, ricollegati e riapri 192.168.1.1.
  5. Nella scheda OTA, alla voce Firmware deve comparire la nuova versione. Se c'è ancora 9.00.0, fermati e leggi «Se qualcosa non va» qui sotto.
Perché prima il firmware?

Alcune prime versioni 9.0.0 hanno un difetto nel caricamento. Se il caricamento del firmware fallisce non cambia niente: il controller tiene il firmware vecchio. Facendo prima il firmware, il passo successivo usa il caricamento corretto.

4 Poi l'interfaccia web

  1. Stesso riquadro. Update Type: Filesystem (web UI)
  2. Binary: scegli littlefs.bin → Upload.
  3. Quando dice che ha finito, ricarica la pagina. Fatto!

Tornare al firmware ufficiale Forbes

Il modo più facile: nel controller, OTA → Release source → Forbes Automotive (official) → Check for updates → Switch to official. Serve internet sul telefono: configura Home WiFi (Bridge Mode) nella stessa scheda OTA.

Niente Wi‑Fi di casa? Scarica i file ufficiali e ripeti i passi 2–4 con questi:

firmware.bin ufficiale littlefs.bin ufficiale

Versione ufficiale: 9.00.0. Se scarichi due volte lo stesso file, l'iPhone salva il secondo come firmware-1.bin: scegli il più recente.

Se qualcosa non va

  • Dopo il passo 3 c'è ancora 9.00.0: il tuo controller ha una delle prime versioni 9.0.0, che non riesce a finire il caricamento. Non è stato cambiato niente. Serve un aggiornamento via USB da un computer, una volta sola (un'officina può usare il programma ufficiale). Dopo, questa pagina funziona dall'iPhone. L'aggiornamento USB può cancellare le impostazioni: esportale prima.
  • Non vedi il Wi‑Fi del controller: si spegne dopo 5 minuti senza traffico CAN. Accendi il quadro.
  • «OTA BLOCKED»: l'auto deve essere ferma con il quadro acceso.
